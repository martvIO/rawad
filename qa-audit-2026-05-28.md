## Priority Fix List

### Critical (ship-blockers)

1. **Driver "متابعة" button** — fix the click handler on `/portal/driver/pending`. The groom-UID lookup or `navigate()` call after username resolves is not executing. Driver has no workaround.

2. **`GET /api/digital/design-requests` → 500** — fix the server-side handler. Check for unhandled exception (missing field access, DB query error) in `functions/src/api/`. The groom correctly submits; the admin can never see it.

3. **`PATCH /api/settings` → 400 on digital mode toggle** — the client sends an unrecognized field on tab switch. Align the field name sent by the mode-switch component with the server's accepted schema.

### Warnings (fix before next user-facing release)

4. **Admin self-delete** — disable "حذف" on the logged-in user's own row, or add a server-side guard blocking deletion of the caller's own UID.

5. **Raw URL in handwritten dashboard recent-deliveries** — replace the text render of `proofUrl` with `<img src={proofUrl} />`, matching what `/proofs` already does.

6. **Map filter counts** — change label to always show total guests (e.g., "الكل (6)") with a separate note about GPS-sharing (e.g., "0 شاركوا موقعهم").

7. **Footer "من نحن" and "اتصل بنا"** — wire to a real destination (WhatsApp, section scroll, or dedicated page) or remove.

8. **Footer "دليل العريس"** — rename to "بوابة العريس" to match actual behavior, or build and link a real guide page.

9. **"تواصل للحجز" pricing CTAs** — route to a WhatsApp link or contact form for unauthenticated users, not the login page.

10. **No "Forgot Password" link** — add "نسيت كلمة المرور؟" to the login screen.

11. **Footer icon buttons** — replace emoji icons with a single ↑ "أعلى" scroll button, or wire them as intended service/social links.

### Info (polish)

12. **Login password field** — wrap username + password + button in a `<form>` element.
13. **Add a 404 page** — catch-all React Router route with an Arabic "الصفحة غير موجودة" message.
14. **Page `<title>` on language switch** — update `document.title` reactively when language changes.
15. **Clean test data from groom account** — remove junk tiers ("lkjj", "gvgn", "ml") and junk guests.
16. **Digital settings default template** — pre-fill the digital-mode message textarea with a sensible Arabic template.
