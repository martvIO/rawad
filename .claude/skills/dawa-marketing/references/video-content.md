# Video Content for Dawa

Produce a shoot-ready short-form video: a hook, a line-by-line script with on-screen text and shot notes, and a CTA. Vertical **9:16**, 15–30s, built for **Reels / TikTok / Facebook**. The skill writes the plan; the user shoots on a phone.

## The rule: win the first 3 seconds

Most viewers decide in 3 seconds and watch **muted**. So every video needs:

- A **hook** in the first 3s — visual + on-screen text, not a slow logo intro.
- **Burned-in Arabic captions** (and Hebrew when targeting that segment) — assume no sound.
- A single clear idea. One video = one message.

## Hook frameworks (pick one, open with it)

- **Problem:** "عندك ٥٠٠ مدعو ومش عارف مين رح يجي؟" (500 guests, no idea who's coming?)
- **Transformation / reveal:** open on the animated digital invitation opening → "هيك بتوصل دعوتك."
- **POV:** "POV: وصلتك دعوة عرس على الواتساب وانفتحت لحالها ✨"
- **Curiosity / pattern-break:** "بطّلنا نوزّع الدعوات بالطريقة القديمة." (We stopped delivering invitations the old way.)
- **Social proof:** "٣٠٠ عروس استخدمت دعوة هالموسم." (real number only.)

## Content pillars (rotate — don't only sell)

1. **Product demo** — the digital invite reveal/envelope animation, the RSVP dashboard filling up live, a per-guest link on WhatsApp.
2. **Emotional moment** — a guest's face receiving a beautiful invite; a couple relieved to see RSVPs come in.
3. **Social proof** — real wedding footage, a couple's testimonial, a screen of confirmations.
4. **Proof-of-delivery** — a driver hand-delivering a printed invitation, photo uploaded — the "we actually deliver" story unique to Dawa.
5. **Education / tips** — "٣ أخطاء بتصير بتوزيع دعوات العرس" — wedding-planning value that earns the follow before the sell.

## Script template

```
HOOK        (0–3s)   On-screen text: [hook line]   Shot: [attention-grabbing visual]
VALUE/DEMO  (3–20s)  Show the feature doing the thing. 2–4 quick cuts.
                     On-screen text per cut: [benefit, not feature name]
CTA         (20–30s) On-screen text + VO: [what to do next]  →  "احجزوا عبر الواتساب 💬"
```

Rules: cut every 2–3 seconds, show the product on screen (don't just talk about it), lead with benefit ("اعرف مين رح يجي") over feature name ("RSVP tracking"), end on **one** CTA to WhatsApp.

## Ten Dawa video ideas to draw from

1. Screen-record the digital invitation opening — the envelope + starfield reveal. (demo)
2. "من الطلب للعرس" — a couple's journey using Dawa start to finish. (emotional)
3. Driver POV delivering invitations across a town, proof photos uploading. (proof-of-delivery)
4. Time-lapse of the RSVP dashboard filling: 0 → 400 confirmed. (demo)
5. "٣ أخطاء بتوزيع الدعوات" listicle. (education)
6. Split-screen: old way (stacks of paper, phone-call chaos) vs. Dawa. (problem→solution)
7. Real couple testimonial, 20s, captioned. (social proof)
8. "شو بيصير لما تبعت دعوة على الواتساب" — POV of the guest receiving it. (POV)
9. Countdown/seasonal: "موسم الأعراس قرّب — جهّزوا دعوتكم." (seasonal)
10. Before/after of a plain WhatsApp text invite vs. Dawa's animated digital invite. (transformation)

## Production notes (for the user)

- Shoot vertical on a phone, good natural light, steady (or gimbal). Clean audio if any voice.
- **Captions are non-negotiable** — burn them in, Arabic (colloquial), Hebrew variant when needed.
- Use **trending audio** on Reels/TikTok (swap per platform); keep VO short so the beat carries.
- Safe zones: keep text away from the top/bottom where the UI covers it.
- Post the same cut natively to each platform (don't share a TikTok watermark to Reels).
- CTA in caption **and** on screen. Pin a comment with the WhatsApp link.

## Deliver

When asked for a video, output: **(1)** the chosen hook, **(2)** the filled script template with on-screen text + shot notes per beat, **(3)** the caption + hashtags, **(4)** the CTA. Give the Arabic version; add Hebrew if that segment is in scope. Pull copy lines from [`ad-copy.md`](ad-copy.md) so the wording matches the ads.
