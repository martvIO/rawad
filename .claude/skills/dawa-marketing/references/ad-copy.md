# Ad Copy & Creative for Dawa

Write the words: Meta ad text, headlines, captions, and A/B variants — in **colloquial Palestinian/Israeli-Arabic** first, with a **Hebrew** variant when that segment is in scope. Every piece ends by driving to a WhatsApp conversation.

## Meta ad anatomy (fill all three)

- **Primary text** (the body, above the image): hook line + 1–2 benefit lines + offer + CTA. Front-load the hook — Meta truncates after ~125 characters, so the first line must land alone.
- **Headline** (bold, under the image): 3–6 words, the core promise. e.g. "دعوات عرسكم بضغطة زر".
- **Description** (small, optional): the offer or reassurance. e.g. "توصيل + دعوة رقمية + متابعة تأكيدات".

## Copy formulas (pick per angle)

- **PAS** — Problem → Agitate → Solution. "عندك مئات المدعوين؟ توزيع الدعوات بياخد أسابيع وبتضيع بالتأكيدات. دعوة بتعملها كلها من مكان واحد."
- **BAB** — Before → After → Bridge. "قبل: فوضى وقصاصات ورق. بعد: كل مدعو موصلته دعوته ومتابعة مباشرة. الجسر: دعوة."
- **AIDA** — Attention → Interest → Desire → Action.

## CTA — always toward WhatsApp

"راسلونا على الواتساب 💬" · "احجزوا دعوتكم اليوم" · "ابعتولنا تاريخ عرسكم ومنرتّبلكم كل شي". Set the click-to-WhatsApp pre-filled opener to something low-friction: "مرحبا، بدي استفسر عن دعوة 💍".

## A/B test matrix — vary ONE thing per test

| Variable | Variants to try |
|---|---|
| **Hook** | question vs. bold claim vs. number ("٥٠٠ دعوة") |
| **Angle** | stress-relief vs. modern-digital vs. proof-of-delivery |
| **Offer** | package price vs. seasonal promo vs. "free digital invite demo" |
| **CTA** | "راسلونا" vs. "احجزوا دورك" vs. "ابعتوا تاريخ العرس" |
| **Creative** | animated invite video vs. driver-delivery clip vs. RSVP-dashboard demo |

Change one variable across ad sets so the winner is unambiguous. When you find a winner, make it the new control and test the next variable against it.

## Guardrails

- Colloquial, warm, celebratory — not corporate MSA.
- Address them as *planning* a wedding, never as if you know their status (Meta personal-attributes rule).
- Every price/number must be real — pull the current package price and any promo from the run inputs; use `[PRICE]` if unknown rather than guessing.
- One emoji-light CTA per ad; don't wall-of-emoji.
